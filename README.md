# _The SBL Greek New Testament_ Aquifer Resource

This repository (`SBLGNT`) contains an Aquifer Bible resource with resource-level metadata and content files in USFM and USX formats.

## Structure

The repository is organized by language codes, with each language folder containing USFM and USX content files.

## Documentation

For more information about the Aquifer platform, data, and metadata formats, visit the [Aquifer Documentation repository](https://github.com/BibleAquifer/SBLGNT).
